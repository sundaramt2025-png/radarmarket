# 💰 Smart Budget & Saving Manager — Full-Stack Web & Android APK

> **Java Mini Project | SE CSE AIML (Academic Year 2026–2027)**  
> **Group Members**: Hansi Yadav, Diksha Kotre, Sakshi Patil  
> **Workflow**: Income → Budget → Expenses → Savings → Goals → Reports

---

## 🎯 Objectives & Features (From PPT)
1. **User Login & Session Management**: Secure access to personal student/user records.
2. **Income Management**: Record and categorize diverse income streams (Salary, Freelance, Investments, Allowance).
3. **Expense Tracking**: Category-wise daily spending ledger with instant budget warnings.
4. **Monthly Budget Limits & Alerts**: Proactive threshold monitors (`80% Caution`, `100% Critical Alert`).
5. **Saving Goals Tracker**: Set targets (e.g. ₹50,000 target), track progress %, and deposit savings with animated milestone bars.
6. **Dashboard & Visual Reports**: Interactive Chart.js graphs matching **Slide 9** (₹30,000 Income, ₹21,500 Expenses, ₹8,500 Net Savings).
7. **Future Scope (Slide 10)**: AI-driven personalized saving tips and daily burn-rate expenditure predictions.
8. **Android APK & PWA Support**: Mobile app shell with tactile haptic feedback, offline service worker caching, and 1-tap APK installation on Android devices.

## 🚀 Quick Start Guide

### Option 1: Python Flask Backend (Recommended)
```bash
python server.py
```
- Open browser at: `http://127.0.0.1:5000`
- Access from mobile phone on the same Wi-Fi using the displayed LAN IP (e.g., `http://192.168.x.x:5000`).

### Option 2: Node.js Express Backend
```bash
npm start
# or: node server.js
```
- Open browser at: `http://127.0.0.1:5000`

### Option 3: Direct Browser Launch (Offline-First)
- Simply double-click `index.html` or open in any browser. All calculations, charts, modals, and local persistence run seamlessly offline via LocalStorage!

---

## 📱 How to Install as an Android App (APK)

1. Open the app URL on **Google Chrome** or **Samsung Internet** on your Android smartphone.
2. Tap the **"Install APK"** button on the top bar or tap the browser menu (**⋮**).
3. Tap **"Install app"** or **"Add to Home Screen"**.
4. Android will automatically package and install **Smart Budget & Saving Manager** as a standalone APK application on your phone's app drawer and home screen.
5. Launches with full-screen experience, splash screen, and offline storage.

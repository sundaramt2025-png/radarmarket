# 📡 RadarMarket

A hyper-local campus marketplace with optical barcode scanning, real-time sync, and proximity radar.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/sundaramt2025-png/radarmarket)

## 🚀 Features
- **📷 Optical Barcode Scanner**: Hardware-accelerated camera scanner with instant ISBN lookup.
- **📍 Hyper-Local Proximity Radar**: Live campus proximity radar for trading textbooks, dorm essentials, and electronics.
- **⚡ Real-Time Multi-User Sync**: Instant listing updates and direct messaging across all connected devices.
- **🔒 Production Ready**: Runs on Flask + Gunicorn, with SQLite database and persistent cloud hosting support.
